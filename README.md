# interferometr trigger

Триггер для помощи в интерферометрических исследованиях станочного оборудования. Телефон закрепите на подвижной оси, детектируйте изменения состояния «движение / покой» и отправляйте клик мыши для захвата измерения.

Для прямого подключения телефона к ПК как мышь следуйте подсказкам в диалоге подключения. Диалог вызывается нажатием на иконку в правом верхнем углу.

Для подключения через ESP-мост: по проводу подключайте ESP через USB OTG-адаптер и разрешите приложению доступ к этому порту. Для подключения по воздуху залейте скетч в ESP32-C3/C6 Dev Module (поддерживается круглый цветной экран с тачскрином или микро OLED 0.43") и следуйте диалогу подключения в приложении на телефоне.

## Использование

1. Установите APK (разрешите установку из неизвестных источников).
2. Откройте диалог подключения — иконка в правом верхнем углу.
3. Выберите связь: **BT HID напрямую к ПК**, **USB OTG** к ESP или **Wi‑Fi SoftAP**.
4. Закрепите телефон на подвижной оси. При смене состояния «движение / покой» приложение отправляет клик мыши для захвата измерения.

Имя Bluetooth-устройства: `ArduHUD Mouse`. Хобби-утилита, лицензия MIT, без гарантий.
