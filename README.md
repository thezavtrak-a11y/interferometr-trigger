# interferometr trigger

Телефон как Windows Bluetooth HID-мышь и опциональный мост к ESP по Wi‑Fi или USB. Личный HUD/триггер для интерферометра: тачпад, клики, прокрутка, датчик на телефоне.

Хобби-утилита «для себя». Лицензия MIT: можно пользоваться и менять для личных целей. Без гарантий.

## Использование

1. Тип связи: **BT HID напрямую к ПК**.
2. **Зарегистрировать HID**.
3. На Windows: Параметры → Bluetooth → Добавить устройство → **ArduHUD Mouse**.
4. Тачпад и клики на телефоне. Прокрутка на HID инвертирована.
5. «Не выключать экран» — чтобы телефон не засыпал во время сессии.
6. В списке типа связи остаются Wi‑Fi SoftAP и USB OTG к ESP (наследие моста).

Имя Bluetooth-устройства по-прежнему `ArduHUD Mouse` (так его ищет Windows).
